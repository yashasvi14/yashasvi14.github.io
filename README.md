# Portfolio Website

Welcome to my personal portfolio website! This site showcases my projects, experience, and skills, and includes links to my GitHub, LinkedIn, and Email for direct contact.

## Live Website
You can visit my portfolio website here:
[https://yashasvi14.github.io/](https://yashasvi14.github.io/)

## About

This portfolio website highlights my journey as a **Data Analyst**, **Data Scientist**, and **Data Engineer**. It includes a section on my professional experiences, academic background, key projects, and skills in areas such as Python, PySpark, SQL, Tableau, Qlik, Power BI, machine learning, and cloud computing (AWS, Azure, GCP).

## Features

- **Light and dark themes**: light by default, with a toggle in the menu that remembers each visitor's choice
- **Experience and education timelines**: recent roles are shown first, and earlier roles (2019–2022) open with a "Show earlier roles" button
- **Skills**: grouped by Languages, Analytics & BI, ML & Databases, and Cloud & Tooling, plus a 3D rotating cloud of skill logos
- **Projects**: cards linking to each GitHub repository
- **Resume chatbot**: a chat button that opens a bot that answers questions about my resume
- **Quick links**: resume, LinkedIn, GitHub, and email from the top of the page and the contact section
- **Responsive layout**: works on phones, tablets, and desktops

## Project Structure

```
index.html            Page content
css/style.css         Styles, including the light and dark themes
js/main.js            Theme toggle, rotating title, menu, earlier roles, chatbot, skills cloud
js/tagcanvas.min.js   3D skills cloud library
images/               Profile photo, favicon, project screenshots, skill logos
```

## Technologies Used

- HTML5, CSS3 (grid layout, light/dark themes) and plain JavaScript, with no framework
- TagCanvas for the 3D skills cloud
- Space Grotesk and JetBrains Mono from Google Fonts
- Resume chatbot embedded from Vercel
- Hosted on **GitHub Pages**
